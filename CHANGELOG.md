# Changelog

## 0.2.0 — 2026-08-24

- Added a simple All Components explorer with search, domain and category filters, compact actions, and pagination.
- Expanded first-run coverage from 12 detailed demonstration families to 530 vendor-neutral starter families across 34 categories.
- Kept all 518 expanded seed records explicitly unscored and unsourced until exact variants, dimensions, ratings, standards, interfaces, and evidence receive human review.
- Updated catalog metadata, offline cache versions, and the downloadable JSON package for the expanded release.

## 0.1.0 — 2026-08-24

- Added the CHANDLER Maker and Curator application shell.
- Added a clearly labeled twelve-family demonstration catalog spanning electronic, electromechanical, and mechanical domains.
- Added deterministic intent and alias search, filters, categories, interfaces, Part Passports, comparison, favorites, local stock, notes, and custom parts.
- Added editable project Bill of Materials workspaces, versioned exports, printable reports, and project baseline snapshots.
- Added Indexed Database API persistence, backup, restore, Fresh Start, theme preferences, a web application manifest, and service-worker caching.
- Added source registry, manual observation import, normalization-rule testing, review decisions, canonical catalog, proposal export, quality gates, releases, and local audit events.
- Added JSON schemas, ingestion command-line tools, fixtures, tests, methodology, governance, source policy, compatibility coverage, and contribution guidance.
