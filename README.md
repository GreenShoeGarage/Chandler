# CHANDLER static build

Version 0.4.0 · catalog 2026.08.25-curated.2 · 244 families · 176 grouped common variants · 141 searchable Flux reference parts · SparkFun KIT-27842 coverage 27/27

Copy every file in this folder to the same directory on your static web server, then open `index.html` through `http://` or `https://`. No server-side runtime, package installation, database, account, or external asset host is required.

For reliable offline caching and browser storage, serve the files from a web server instead of opening `index.html` with a `file://` address.
