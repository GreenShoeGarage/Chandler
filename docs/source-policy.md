# Source and licensing policy

Prefer official Application Programming Interfaces, downloadable Bills of Materials, structured project files, and clearly licensed repositories. Record terms status, robots-policy status, license, attribution, rate limits, authentication, adapter version, import timestamps, errors, and maintainer notes before collection.

Do not automatically copy supplier prose, images, drawings, or Computer-Aided Design models. Link to an asset and record its license unless redistribution permission is clear. Never place supplier credentials in the browser. Cache external facts with timestamps and explicit live, cached, manual, stale, or Unknown states.
