# Contributing

Code and structured catalog changes may be proposed through pull requests. Include tests and update documentation when behavior or schema changes.

Catalog changes must include source provenance, original wording, dimensions and units, use case, limitations, license status, and applicable interface records. Compatibility claims require constraints and evidence; Class A and Class B mechanical claims require a named human reviewer.

Makers may open Curator Mode → Community Proposals, select a proposal type, describe the change, add a supporting source, and export the resulting JSON file.
